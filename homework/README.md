# Homework Assignments

This folder contains weekly homework assignments for the Python Data Science course.

## Assignment Structure

Each homework assignment corresponds to a course module and includes:

- **Learning Objectives**: Clear goals for each assignment
- **Exercises**: Hands-on coding exercises with varying difficulty levels
- **Requirements**: Specific tasks and deliverables
- **Questions**: Written questions to test understanding
- **Grading Rubric**: Point distribution and evaluation criteria

## Instructions for Students

1. **Complete assignments in order** - Each assignment builds upon previous concepts
2. **Read all instructions carefully** - Pay attention to requirements and learning objectives
3. **Run all code cells** - Ensure your code executes without errors
4. **Answer all questions** - Provide thorough written responses
5. **Submit on time** - Follow the course submission guidelines

## Submission Guidelines

- Complete all exercises in the notebook
- Run all code cells and ensure they execute without errors
- Answer all written questions thoroughly
- Save your notebook with all outputs
- Submit the completed notebook to your instructor

## Grading

Each assignment is worth 100 points total. Points are distributed across different exercises based on complexity and learning objectives. See individual assignment files for detailed grading rubrics.
